1. **only**: one corrected example per target block (128 updates).
2. **triple**: immediately repeat that corrected example twice (384 updates).
3. **boundary-repeat**: target, a crossed boundary example, repeat that boundary

4. **boundary-history**: same target example, same crossed boundary example,
   then a valid historical example of the SAME channel/priority (384 updates).

Both boundary arms get exactly the same correction/boundary examples and order;
the third update changes only the historical identifier versus boundary repetition.

or examples enter inference context. Both arms' third-update route labels and
conditions match, but identifier diversity and token costs differ. The small
set already rehearses behavior, so this cannot isolate pure scope information
from rehearsal or identify a protected internal computation. Extra history
