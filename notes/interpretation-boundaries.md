# What this comparison can distinguish

The new-channel block is meaningful later learning only if the amber/teal
routing is acquired. It shares syntax, argument transformations and output tools
with the original task; it does not represent arbitrary unrelated language
learning. Report all branches even if new learning fails.

Forgetting compares the identical old queries under the unchanged old rule.
Revision changes the reference rule only for copper/fast. On that scope, a stale
old answer is not successful retention. Outside it, old answers remain valid.
Copper/slow is the strongest test of an overbroad copper routing change; the two
violet combinations already used marten. Amber/teal tests whether correction
disrupts the most recently learned relations as well as the original ones.

A correction consists of positive checked examples, not an authoritative verbal
statement of the entire scope. Copper/fast-only evidence alone is consistent
with multiple possible new rules. Replaying copper/slow therefore supplies
boundary evidence as well as rehearsal. A replay benefit cannot isolate an
internal parameter-locality mechanism from improved identification of scope.
The update-matched target repetition controls exclude only the explanation
that replay's benefit is due to the number of optimizer steps alone. They do
not equalize semantic information, label diversity or answer-token counts.

The explicit-example arm has the same pretrained base and retains teaching
context at inference. The development revised context replaces four old scoped
labels and appends four new corrections; this includes four additional corrected
old examples that gradient revision does not receive. Disclose this access
asymmetry; a final fairer context can instead remove obsolete records and append
only the four actual corrections. Such an amendment must precede fresh evaluation.
No complete verbal rule should silently enter an example-only reference.

The component routing metric requires a syntactically valid call and the correct
tool name; identifier and suffix are scored independently within that form.
Whole-call exactness also requires the exact uppercased identifier and suffix.
Outputs are proposed calls, not externally executed actions. Reliable routing
does not prove reliable end-to-end performance or a learned symbolic program.

The inherited CE and forward-KL checkpoints share seed 41 and prior examples;
they are different acquired states, not independent training-seed replications.
Fresh random identifiers can test new-input behavior under a fixed recipe but
cannot turn deterministic repeated training into an independent acquisition
replication. Counts apply to the tested workload; do not interpret crossed
conditions from one identifier as independent trials or make universal claims.

The investigator supplies the true correction scope to replay selection: the
program excludes exactly copper/fast A records. This is an oracle-assisted
validity mask, not a learned discovery of which history is obsolete. The cleaned
explicit-example reference receives the same filtering. The mask and extra
boundary examples are part of those treatments' information access; their
construction cost and correctness must not be attributed to the adapter.
